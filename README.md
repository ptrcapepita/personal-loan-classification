# Bank Personal Loan Classification with Neural Network

This project focuses on classifying personal loan eligibility using a neural network model on a banking dataset. Through comprehensive data exploration, preprocessing, and neural network modeling, it aims to accurately predict loan eligibility.

## Project Overview
The main objectives of this project are:
- **Data Exploration and Preprocessing**: Analyzing and preparing data by checking for outliers, performing univariate and multivariate analysis, and handling data imbalance.
- **Neural Network Modeling**: Developing a neural network model, experimenting with different layers and node configurations to enhance model performance.
- **Hyperparameter Tuning**: Leveraging Bayesian Optimization to achieve optimal accuracy.

### Key Achievements:
- Conducted thorough data preprocessing to ensure high-quality input features.
- Built and fine-tuned a neural network model with optimized layer structures for personal loan classification.
- Achieved 90% accuracy through Bayesian Optimization for hyperparameter tuning.
